# Demo TODO

Минимальный пример пользовательского продукта в Атласе, чтобы показать: Сима умеет вести **любой** продукт, не только сама себя. Этот проект используется как демо и эталон для PR5+.

## Цель
Простой TODO-планировщик: пользователь добавляет задачи, отмечает их выполненными, фильтрует по проектам/тэгам. Опционально LLM подсказывает категорию для новой задачи.

## JTBD

## North Star
Время от «придумал задачу» до «записана и отнесена в правильный список» < 5 секунд.

## Что не входит в скоуп
- Совместная работа / шаринг.
- Email/push-нотификации.
- Платная подписка.

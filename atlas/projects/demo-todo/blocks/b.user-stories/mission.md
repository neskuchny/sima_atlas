# b.user-stories — mission

Каноничный набор пользовательских историй продукта Demo TODO. Этот блок — единая точка правды для UI и API: они оба должны реализовать поведение, описанное здесь. Если очередная фича не описана как user-story, она не входит в MVP.

## Layer
user

## User Stories (MVP)

1. **US-1 Add task.** Я вижу пустое поле сверху списка; ввожу строку и Enter — задача появляется первой в списке с текущим временем.
2. **US-2 Toggle done.** Кликаю по чекбоксу слева от задачи — она становится зачёркнутой, перемещается в подсписок «Сделано».
3. **US-3 Delete.** Нажимаю иконку корзины — задача удаляется без подтверждения; есть undo-toast 5 секунд.
4. **US-4 Filter by category.** В шапке вижу chips-фильтр со всеми категориями; клик оставляет только задачи этой категории.
5. **US-5 Suggested category.** При наборе текста задачи под полем появляется suggested-chip от LLM-категоризатора (если он включён); клик подставляет категорию.

## Out of scope (для MVP)
- Drag & drop reorder.
- Sub-tasks / иерархия.
- Sharing / collaboration.
- Push-уведомления.

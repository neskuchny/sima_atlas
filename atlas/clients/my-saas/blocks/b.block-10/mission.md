# b.block-10 — mission

CLI-скрипт аналитики звонков риелторов: принимает поток записей звонков (NDJSON/JSON Lines) с расшифровкой и метаданными, считает агрегаты (объём текста, длительность, тематические маркеры, разрез по агентам) и выводит один JSON-отчёт в stdout. Данные только из входа, без встроенных демо-звонков.

# b.block-10 — user story

**Как** руководитель отдела продаж или аналитик агентства недвижимости  
**Когда** накоплены расшифровки телефонных разговоров риелторов с клиентами (экспорт в JSON Lines)  
**Я хочу** одной командой получить сводку: сколько звонков, объём диалогов, упоминания ключевых тем (ипотека, показы, цена, объект) и разрез по агентам  
**Чтобы** оценивать качество коммуникаций и нагрузку без ручного прослушивания каждого звонка

_Acceptance — нижний слой; user story — верхний. LLM-валидатор проверяет что код реально решает эту историю, а не выполняет acceptance формально._

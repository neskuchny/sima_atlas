# b.block-9 — user story

_(Phase Q-1: что пользователь делает, ожидает увидеть, и почему ему это нужно)_

**Как** [персона]
**Когда** [триггер / контекст]
**Я хочу** [действие]
**Чтобы** [outcome / value]

_Acceptance — нижний слой; user story — верхний. LLM-валидатор проверяет что код реально решает эту историю, а не выполняет acceptance формально._

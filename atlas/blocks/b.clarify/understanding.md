# b.clarify — understanding

_Объявлено исполняющим агентом до кода для R-8.12 (взято из OpenSpec и Spec
Kit). Заголовки английские — их читает машина; содержание — на языке миссии.
Перезаписывает объявление R-8.09, которое ждало ответа: рамка блока теперь
шире, история — в git._

## Treating this as

Две вещи, которые показывают человеку смысл контракта, а не его файлы:
«что изменилось в требованиях с момента, когда вы сказали „верно“» — как
просмотр изменений в код-ревью, только по требованиям (добавлено /
изменено / удалено по A1…, KPI-1…, разделам миссии), и «где формулировка
контракта не проверяема» — как линтер, но для требований: размытые слова
без меры, KPI без числа, KPI, который никто не проверял. Не новый арбитр и
не гейт.

## In scope

- Снимки контракта (mission / acceptance / kpi / user_story) в момент
  объявления и ответа оператора, по содержимому — чтобы было с чем сравнить.
- Разница по единицам смысла: проверки приёмки по id, KPI по номеру,
  разделы миссии по заголовку; внутри изменённой единицы — было / стало.
- Разница на «Обзоре», когда рамка устарела, и в промпте переобъявления.
- Детерминированная проверка формулировок (без LLM): размытые слова без
  меры в KPI и приёмке, KPI без меры, KPI без проверки и без замера,
  проверки только на судье. Отчёт, не гейт; строка на «Обзоре».

## Out of scope

- Папки изменений OpenSpec как единица работы: у нас единица — блок.
- Обязательный формат сценариев GIVEN/WHEN/THEN.
- Проверка формулировок через LLM (это уже вопросы b.clarify).
- Правка контракта по находкам: находка — повод для человека, не для кода.

## Variant chosen

- Снимки — файлы по хэшу содержимого в папке блока (одинаковые версии не
  дублируются), а не текст внутри журнала рамки: журнал остаётся коротким.
- Разница по единицам смысла, а не построчная: оператор читает «изменён
  KPI-7», а не номера строк.
- Качество формулировки входит в ту же сводку смысла блока, что и рамка:
  один читатель для отчёта и канваса.

## Assumed without asking

- «Мера» — это число, процент, сравнение или квантор («каждый», «ни один»,
  «всегда», «ноль»): «каждый прогон возвращает X» измеримо без цифры.
- KPI считается проверенным, если на него ссылается проверка приёмки или
  он упомянут в строке замера `kpi` в checks.log.
- Для объявлений, сделанных до снимков, разница недоступна — показываются
  только изменённые файлы, и об этом говорится прямо.

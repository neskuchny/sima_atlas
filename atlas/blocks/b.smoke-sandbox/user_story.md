## User Stories

**Как** разработчик тестов / **Когда** я запускаю smoke-тесты / **Я хочу** иметь изолированную песочницу / **Чтобы** мои тесты не влияли на другие блоки и данные.

**Как** CI / **Когда** выполняются автоматические тесты / **Я хочу** использовать smoke-sandbox / **Чтобы** убедиться, что основные функции Атласа работают корректно в изолированной среде.

**Как** новый контрибьютор / **Когда** я изучаю кодовую базу / **Я хочу** понимать, что b.smoke-sandbox используется только для тестов / **Чтобы** не запутаться в его предназначении и не использовать его в production-коде.

**Как** DevOps / **Когда** я наблюдаю за состоянием системы / **Я хочу** видеть логи smoke-тестов в b.smoke-sandbox / **Чтобы** быстро выявлять и устранять проблемы в тестовой среде.

**Как** архитектор / **Когда** я проектирую новые фичи / **Я хочу** быть уверенным, что b.smoke-sandbox не используется в production / **Чтобы** избежать непредвиденных зависимостей и проблем в будущем.

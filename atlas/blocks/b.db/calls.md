# b.db — calls

Что этот блок вызывает во время работы: запускает отдельным процессом или
вызывает по HTTP. Это не зависимость для порядка сборки — её пишут в
depends_on.md, и она не может замыкать цикл. Вызов может идти «вверх», к
блоку, который сам зависит от этого. Каждую строку подтверждает код: карта
кода и проверка графа кода сверяют их с тем, что код делает.

- b.acceptance-verifier-loop: change_set.mjs запускает verify_block_acceptance.mjs — набор изменений перепроверяет приёмку блоков, которые затронул
- b.agent-orchestrator: apply_ingestion_queue.mjs запускает analyze_conversation_to_atlas.mjs — разговор, приложенный к заметке в очереди памяти, разбирается в предложения блоков
- b.user-docs-generator: log_transition.mjs запускает generate_user_docs.mjs — после перехода статуса у блока, который видит пользователь, пересобирается его пользовательская документация

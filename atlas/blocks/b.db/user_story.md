## User Stories

**Как** архитектор Atlas / **Когда** я обновляю блок / **Я хочу**, чтобы изменения записывались атомарно / **Чтобы** не возникало повреждений данных при сбоях.

**Как** архитектор Atlas / **Когда** происходит изменение блока (mission, KPI, depends, provides) / **Я хочу**, чтобы создавалась запись в истории изменений / **Чтобы** можно было отслеживать эволюцию блока.

**Как** разработчик Atlas / **Когда** схема `graph.json` меняется / **Я хочу**, чтобы старые блоки автоматически обновлялись / **Чтобы** обеспечить совместимость данных.

**Как** UI или MCP / **Когда** мне нужно получить данные о блоке, его зависимостях или истории / **Я хочу**, чтобы был единый API для чтения / **Чтобы** упростить доступ к данным и избежать дублирования логики.

**Как** пользователь Atlas / **Когда** я добавляю информацию из встречи в блок / **Я хочу**, чтобы можно было указать, какая именно информация из встречи используется / **Чтобы** можно было легко отслеживать происхождение данных.

**Как** пользователь Atlas / **Когда** я создаю связи между блоками / **Я хочу**, чтобы можно было указать тип связи / **Чтобы** AI мог правильно анализировать взаимосвязи между блоками.

**Как** пользователь Atlas / **Когда** я добавляю артефакт в блок / **Я хочу**, чтобы можно было добавить ссылку на существующий блок, документ или схему / **Чтобы** можно было легко объединять информацию из разных источников.

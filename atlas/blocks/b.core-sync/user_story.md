## User Stories

**Как** архитектор платформы / **Когда** я определяю зависимости между блоками / **Я хочу** чтобы система автоматически проверяла консистентность контрактов (provides/depends_on) / **Чтобы** избежать ошибок интеграции и рассинхрона.

**Как** разработчик / **Когда** я вношу изменения в код блока / **Я хочу** чтобы система автоматически проверяла соответствие изменений заявленным целям и KPI блока / **Чтобы** убедиться, что мои изменения не приводят к отклонению от миссии.

**Как** руководитель разработки / **Когда** я анализирую состояние блока / **Я хочу** чтобы система предоставляла отчет о синхронизации между миссией, KPI, кодом и зависимостями / **Чтобы** быстро выявлять и устранять расхождения и поддерживать актуальность блока.

## User Stories

- **Как** архитектор / **Когда** я открываю UI / **Я хочу** видеть схему монорепо в виде слоёв и блоков / **Чтобы** понимать структуру и связи между проектами.
- **Как** техлид / **Когда** я смотрю на канвас / **Я хочу** видеть статус блоков (idea/wip/review/done/broken/drift) / **Чтобы** быстро оценивать прогресс и проблемные места.
- **Как** разработчик / **Когда** я выбираю блок / **Я хочу** видеть его mission/kpi/tasks/checks / **Чтобы** понимать его назначение и критерии готовности.
- **Как** DevOps / **Когда** я вижу рассинхронизированный блок / **Я хочу** видеть подсветку и причину рассинхрона / **Чтобы** быстро находить и устранять проблемы.
- **Как** любой участник команды / **Когда** я работаю с блоком / **Я хочу** иметь возможность запустить действия по блоку (Implement / Review / Done / Rollback / mark-dead) / **Чтобы** управлять жизненным циклом блока.
- **Как** архитектор / **Когда** я выбираю блок / **Я хочу** иметь возможность экспортировать context-pack / **Чтобы** передать контекст агенту.
- **Как** инвестор / **Когда** я смотрю на канвас / **Я хочу** видеть общую картину прогресса и проблем / **Чтобы** понимать, куда движется проект и какие риски существуют.
